# 实际练度散件排班

2026-09-22 修复：自动排班不再要求散件主班和普通替补解锁全部基建技能。

- 组合仍走原有技能准入检查；组合成员不足或技能未解锁时，不虚构组合加成。
- 制造、贸易散件按当前精英阶段和等级的已解锁技能排序，保留对未支持联动的过滤。
- 组合候选无法补齐时，对生产设施、中枢和发电站的主班及独立替补进行统一匹配。优先使用有收益的散件，必要时使用在该设施无技能加成的已持有干员；模拟仍按其真实技能计算。
- 匹配保留已有人员占用，不借用未持有干员，不重复分配普通替补；宿舍空位作为 Free 休息床位。
- 缺少但书或龙舌兰时，只配置实际已持有且已解锁技能的跑单人员。
- 分支数为候选上限，有至少一套有效候选即可进入模拟；完全无法补齐时说明主班/独立替补不足。
- 所有候选仍必须通过动态模拟，不能将生成成功等同于模拟成功。

回归入口：`src/optimizer/inventoryFallback.spec.ts`。覆盖精零一级、缺少跑单干员、锁定工位、空/极小干员池和 24 小时预热 + 72 小时采样。混合练度数据来自用户提供的练度表，仅保留干员代号、精英阶段、等级。
