# 2026-09-08 更新说明

## 本轮目标

以可在 Mower 正常运行的 `252二赤金Test.json` 为回归样本，修复导入后错误校验、干员名称显示、跑单启用和旧计算桥接问题，同时保持产出算法文件不变。

## 已完成

- 校验与界面信息使用中文干员名，不再向用户显示 `char_4032_provs` 等内部 ID。
- 允许同一但书出现在多个贸易站的有序候选列表；同一槽内重复候选仍会报错。
- 1/2 级贸易站启用仅但书跑单；3 级贸易站沿用但书与龙舌兰跑单规则。
- 菲亚梅塔在宿舍中的替补列表被识别为心情交换目标，可引用当前主力，不再误报普通替补冲突。
- 普通宿管不再被要求设置替补；宿舍 `Free` 不再被当作非法空席。
- Mower 工作区完整保留替补顺序；送入旧引擎时，按顺序选择未在岗且未被占用的唯一候选，宿舍与右侧设施不进入旧 `operatorBackups`。
- 导入房间从非贸易设施变为贸易站时，自动使用跑单版默认 `shiftRun`，避免继承错误的 `specialOrder=none`。
- 新增真实 252 二赤金 fixture、校验测试、兼容投影测试和 `import -> validate -> calculate` 端到端回归。
