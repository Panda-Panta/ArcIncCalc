# 跑单分支范围与修复验收

本分支使用理想跑单，特殊奖励只允许但书、龙舌兰。该约定覆盖早先自然跑单的默认规则。

- 常驻阵容按正常效率获取普通订单；完成瞬间应用已配置的但书或龙舌兰效果。
- 不实际调动跑单干员，不增加等待，不消耗跑单心情、床位或无人机；两站可以同刻使用同一跑单干员。普通主班、替补及资源规则仍受原有约束。
- 一、二级贸易站配置但书；三级站配置但书及龙舌兰。四赤金单使用龙舌兰，其余符合条件的普通赤金单使用但书，奖励不叠加。
- 配置沿用 Mower replacement[0] 格式以便导出。普通替补紧随其后，普通换班排除专用跑单候选。
- 自动生成先得到 10 套不同且通过物理布局校验的分支，再将全部 10 套送入模拟。旧 trials/Top-K 配置不截断；数量不足时明确阻断，不拿重复方案补数。
- 模拟中途停止的候选不使用半程产出参与成功方案排名。布局合法与长时间模拟完成是两个独立验收项。
- 缺少必需跑单干员或技能未解锁时明确报错；禁止佩佩、可露希尔、U-Official 进入贸易站主班或候补，其他设施不受此限制。

产品入口（自动排班、动态模拟、工作台计算）统一使用 ideal。底层保留显式 natural/drone 模式以验证旧执行器；产品界面不提供这些模式。

验证：idealRunOrder.spec.ts 覆盖同时结算、已占位及零心情跑单干员、虚拟床位、三级互斥结算；smartRosterBranches.spec.ts 覆盖先构造再全量模拟及旧参数兼容；shiftRunContract.spec.ts 覆盖禁止订单、库存、候补与十套物理合法分支。
