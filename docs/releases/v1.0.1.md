# v1.0.1 跑单排班版

修复导入低练度干员库后，计算在 0 小时中断、界面却显示成功且产出全为零的问题。动态模拟现在按每名干员的精英阶段和等级选择已解锁技能，未解锁技能不计入收益；未完成的模拟显示原因并保留日志。

## 更新

- 理想跑单只使用但书与龙舌兰：订单完成瞬间应用奖励，忽略跑单进驻冲突，不增加换人等待，不消耗跑单心情、床位或无人机；普通订单获取时间仍按常驻阵容计算。
- 自动排班先生成 10 套不同且无布局冲突的分支，再全部进入动态模拟。未完成的候选不以半程产出参与成功方案排名。
- 制造、贸易、中枢联动、心情消耗、宿舍恢复、订单容量及跑单奖励读取本次计算的实际技能快照，不修改干员库或共享技能目录。
- 低级但书、龙舌兰技能可以跑单，奖励及虚拟赤金折算按实际已解锁版本计算。
- 修复失败报告被转换为零产出、重新计算后残留旧结果，以及只指定模拟时长时遗漏生产模拟的问题。
- 静态组合模板的满技能适用范围与动态模拟准入检查分开。

## 验证

- 全量回归：997 项通过、1 项跳过；类型检查、前端构建、Windows 桌面编译通过。
- 原排班保留夜烟、格雷伊、特克诺、斥罪精英 0、等级 1，完成 72 小时预热和 168 小时采样。
- 已在 Windows 桌面整合包实际点击“计算产出”，确认显示非零收益和“模拟计算完成”，原排班与干员库保持一致。
- 252 布局、贸易站 2＋1 级、制造站 33332、右侧满级的生成追踪验证了 10 套不同的合法初始分支及理想跑单事件。

## 下载与使用

下载 `ArcIncCalc-Windows-x64-Portable.zip`，完整解压后运行 `ArcIncCalc/ArcIncCalc.exe`。请保留同目录的 `dist` 文件夹。需要 Windows 10/11 64 位和 Microsoft Edge WebView2 运行时；无需安装 Node.js 或启动 Web 服务。

`SHA256SUMS.txt` 提供压缩包校验值，包内 `BUILD-INFO.json` 标明版本、源码提交与验证信息。

本版延续预发布状态。潜在产出与理想跑单采用程序中列明的假设；尚未量化技能会保留诊断，有限候选搜索不保证全局最优。
