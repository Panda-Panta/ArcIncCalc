明日方舟基建排班与全动态收益测算器 (ArcIncCalc)
===================================================

【使用说明】
1. 本程序为解压即用整合包，无需安装 Node.js、无需手动启动 Web 服务。
2. 双击运行当前目录下的「ArcIncCalc.exe」即可直接打开桌面窗口。
3. 请保持当前目录各依赖库与「dist」资源文件夹完整，请勿移动或删除相关文件。

【系统要求】
- Windows 10 / Windows 11 (64 位)
- 系统自带 Microsoft Edge WebView2 运行时（Win10/11 通常默认内置）
  若启动提示缺失运行时，可前往微软官方下载安装：
  https://developer.microsoft.com/en-us/microsoft-edge/webview2/

【功能简介】
- 排班编辑与可视化：支持导入 Mower JSON / 二维码排班图，支持自由修改设施等级（252/333/153 布局）。
- 全动态模拟仿真：内置 82 算法与 Mower 跑单规则，支持整小时暖机跳变、理想跑单、无人机加速贸易站等。
- 宿管与技能联动：自动适配群单宿管组合，菲亚梅塔动态优先最慢宿舍。
